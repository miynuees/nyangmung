이미 사용하고 있는 분들은 오른쪽 버튼을 눌러 업데이트하면 하루에 한 번 자동으로 업데이트됩니다.업데이트
파란 경고창이 뜨면 "추가 정보" → "실행"을 눌러 주세요.

이런 걸 해요

오늘 급식 · 날씨우리 학교 급식과 날씨를 보여 줘요. 비 오는 날엔 우산을 챙기라고 해요.
할 일 · 일정적어 두고 체크해요. [말풍선 고정]을 누르면 머리 위에 쪽지로 떠 있어요.
Claude 작업 알림Claude Code가 하는 일을 말풍선으로 알려 주고, 허락 버튼을 대신 눌러 줘요.
모습 꾸미기고양이·강아지, 무늬, 소품, 도트 그림을 골라요. 간식도 줄 수 있어요.
🖱️옆의 ≡ 버튼은 오늘, ⚙ 버튼은 설정. 끌면 자리를 옮겨요.
🔒할 일·일정은 내 컴퓨터에만 저장돼요.
📖자세한 설명은 사용안내에 있어요.

업데이트 기록

v1.7.0에서 바뀐 것

  • 할 일·일정을 말풍선에 고정할 수 있어요. ≡ 오늘 → 할 일이나 일정 탭에서 [말풍선 고정]을 누르면 냥멍이 머리 위에 노란 쪽지가 계속 떠 있어요. 쪽지의 동그라미를 누르면 바로 완료돼요.
  • 바탕화면에만 둘 수 있어요. 설정 → "화면에 있을 곳"을 [바탕화면에만]으로 바꾸면 다른 창 뒤에 있다가 바탕화면을 볼 때(Win+D)만 보여요. Claude가 허락을 기다릴 때는 잠깐 앞으로 나와요.
  • 설정을 줄였어요. 기지개 권유·어슬렁 걷기·먼저 말 걸기·깨어 있기는 이제 늘 켜져 있어요.
지난 버전 더 보기

v1.6.5에서 바뀐 것

  • 업데이트 뒤 말풍선이 짧아졌어요. [바뀐 것 보기]를 누르면 이 페이지에서 바뀐 내용을 볼 수 있어요.
  • 냥멍톡을 같이 쓰는 컴퓨터에서 업데이트할 때, 클로드 말풍선 연결을 냥멍톡에서 가져오지 않아요.

v1.6.4에서 바뀐 것

  • 도트 강아지 얼굴을 다듬었어요 — 도트 그림으로 볼 때 강아지 코와 주둥이를 작게 하고 입을 연하게 해서 더 동글동글해졌어요.

v1.6.3에서 바뀐 것

  • 도트 그림을 골라 볼 수 있어요 — 설정 → 모습에서 [도트 그림]을 누르면 냥멍이가 옛날 게임 같은 도트 그림으로 바뀌어요. 무늬·소품·강아지 모두 돼요. [기본 그림]을 누르면 원래대로 돌아와요.
  • 글씨체가 프리텐다드로 바뀌었어요 — 말풍선·메뉴·설정 글씨가 더 또렷해졌어요.
  • 흐릿함을 고쳤어요 — 화면 배율을 125%·150%로 키운 노트북에서 냥멍이와 글씨가 흐릿하던 걸 고쳤어요.
  • 업데이트되면 바뀐 것을 말풍선으로 알려 드려요.

v1.6.2에서 바뀐 것

  • 할 일·일정이 5개 넘어도 전부 볼 수 있습니다 — 전에는 5개까지만 보이고 "그 뒤로 몇 개 더 있어요"라는 글자만 나왔습니다. 이제 목록 아래 "다음 ▸ / ◂ 이전"을 누르면 5개씩 넘겨 볼 수 있고, 넘긴 쪽에서 바로 체크하거나 지울 수 있습니다.

v1.6.1에서 고친 것

  • 바로가기를 눌러도 "유효하지 않다"며 안 켜지던 문제 — 바로가기가 가리키던 주소가 컴퓨터에 따라 없는 길이 될 수 있었습니다. 바탕화면·시작메뉴 바로가기를 모두 고쳤고, 컴퓨터 켤 때 자동으로 나오게 해두신 분은 그 바로가기도 같이 고쳐집니다. 이름·학교·할 일·일정은 그대로 남습니다.

v1.6.0에서 바뀐 것

  • 가끔 어슬렁 걸어다닙니다 — 일이 없고 조용할 때, 1~2분에 한 번쯤 옆으로 뒤뚱뒤뚱 걸어갔다가 잠깐 서서 두리번거리고 제자리로 돌아옵니다. 손으로 옮겨 둔 자리를 집으로 기억해서 그 근처에서만 다니고, 화면 끝에 닿으면 돌아섭니다. 말을 걸거나 붙잡거나 일이 시작되면 그 자리에서 멈춥니다. 돌아다니는 게 번거로우면 설정 ⚙의 "가끔 어슬렁 걸어다니기"를 끄면 됩니다.

v1.5.0에서 바뀐 것

  • 업데이트를 알아서 합니다 — 전에는 새 버전이 나오면 "받을까요?" 하고 물어보고, 눌러야 갈아입었습니다. 이제는 묻지 않고 조용히 갈아입은 뒤, 다시 켜지면서 "새 버전으로 바뀌었어요" 한마디만 합니다. 누를 것이 없습니다. (일하는 중일 때는 건드리지 않고 다음날 합니다)

v1.4.9에서 고친 것

  • 눌러도 엉뚱한 데가 눌리던 문제 — 화면 배율(글자·앱 크기)을 125%·150%로 쓰는 컴퓨터에서 냥멍이가 크게 보이고, 눌러도 빗나가거나 반응하지 않던 것을 고쳤습니다. 이제 어떤 배율에서도 보이는 자리 그대로 눌립니다.

v1.4.8에서 바뀐 것

  • 새 버전 확인 — 설정 갈래에 있던 '새 버전 확인' 줄을 없애고, 설정창 제목 오른쪽 끝에 작은 '새 버전 확인' 글자로 옮겼습니다. 눌러서 확인합니다.

v1.4.6에서 고친 것

  • 간식 먹는 모습 — 그릇 쪽으로 고개를 뻗다가 머리가 몸에서 떨어져 보이던 걸 고쳤습니다. 이제 그릇이 앞발 사이에 놓이고, 그 자리에서 고개만 까딱이며 먹습니다.

v1.4.5에 생긴 것

  • 날씨 — 급식 옆에 오늘 날씨가 뜨고, 비 오는 날 아침엔 우산을 챙기라고 말해줍니다.
  • D-day 챙기기 — 시험·행사는 물론 직접 넣은 일정도 골라두면 며칠 남았는지 계속 보여줍니다.
  • 집중 타이머 — 30분·50분, 또는 원하는 시간을 직접 정해서 쓸 수 있습니다. 그동안 조용히 옆에 있다가 끝나면 같이 기지개를 켭니다.
  • 간식과 소품 — 왼쪽 그릇 버튼으로 간식을 줍니다. 고양이는 사료·생선·통조림, 강아지는 사료·뼈다귀·육포. 머리에는 베레모·리본·꽃·안경·왕관을 씌울 수 있습니다.
  • 설정창 정리 — 모습 / 내 정보 / 설정 세 갈래로 나눠 한눈에 보이게 했습니다.
  • 새 버전 알림 — 이제 새 버전이 나오면 냥멍이가 먼저 알려주고, 눌러주면 알아서 갈아입습니다.

바탕화면에 친구 냥멍이와 단체방 집을 띄워 두고, 메시지가 오면 말풍선으로 받아요.

이렇게 써요

대화 창 열기

  1. 내 냥멍이를 두 번 클릭해요.
  2. 💬 대화를 눌러요.
  3. 처음이면 닉네임을 정해요. 세니#2048 같은 내 코드가 생겨요.

친구 추가하기

  1. 📋 복사를 눌러 내 코드를 친구에게 알려 줘요.
  2. 친구 코드를 받으면 🐾 친구를 눌러요.
  3. 코드를 넣고 ➕ 추가. 끝!

바탕화면에 친구 띄우기

  1. 🐾 친구 목록에서 화면에 띄우기를 눌러요.
  2. 친구 냥멍이가 바탕화면에 나와요. 끌어서 원하는 곳에 두면 돼요. (최대 6명)
  3. 클릭하면 한 줄 메시지, 두 번 클릭하면 대화 창이 열려요.

단체방 집 만들기

  1. 💬 새 대화에서 친구를 여러 명 골라 단체방을 만들어요.
  2. 단체방 위쪽 🏠 집 띄우기를 눌러요.
  3. 집을 오른쪽 클릭 → 🏠 모양에서 7가지 집 중에 골라요.

메시지가 오면

  1. 냥멍이 위에 카드가 떠요. 답장을 누르면 바로 답해요.
  2. 놓친 메시지는 분홍 숫자로 남아요. 누르면 다시 보여요.
  3. 수업 중엔 대화 창 위 📚 수업 중을 눌러 두면 조용해요.
⏳메시지는 하루가 지나면 사라져요.
🐾냥멍이 기능(급식·할 일·Claude 알림)도 그대로 있어요.
📖자세한 설명은 사용안내에 있어요.

v0.2.5에서 바뀐 것

  • 내 냥멍이에게도 👑 이름표가 생겼어요. 친구 냥멍이와 같은 높이로 서요.
  • 내 냥멍이도 작업 표시줄 아래로 숨거나 화면 밖으로 나가지 않아요.
  • 겹쳐 있는 친구 냥멍이가 잘 눌려요. 겹친 부분을 누르면 뒤에 있는 다른 프로그램이 눌리던 문제를 고쳤어요. 겹쳐 있으면 앞에 보이는 친구가 잡혀요.
  • 다른 프로그램 창이 냥멍이 위를 덮어도 곧 다시 냥멍이가 맨 위로 올라와요.

v0.2.4에서 바뀐 것

  • 내 냥멍이도 친구들과 놀아요 — 깨어 있는 친구가 옆에 있으면 서로 ♥ ♪ 인사를 하고, 가끔 친구가 내 냥멍이 옆으로 걸어와서 공을 주고받아요. 내 냥멍이를 친구 옆에 끌어다 놓아도 인사해요.
  • 클로드가 일하는 중이거나 말풍선·메뉴가 떠 있을 땐 놀지 않아요.

v0.2.3에서 바뀐 것

  • 냥멍이·친구 냥멍이·집이 조금 작아졌어요 (80%). 친구 냥멍이와 내 냥멍이가 같은 크기예요.
  • 캐릭터 바로 옆 빈 곳을 누르면 뒤에 있는 바탕화면·프로그램이 눌려요. 클릭 범위를 캐릭터에 딱 맞게 줄였어요.
  • 한 줄 메시지 칸에 누구에게 보내는지 나와요. (예: 메시지 보내기 · 워니 님에게)

v0.2.2에서 바뀐 것

  • 한 줄 메시지 칸 오른쪽 위에 × 닫기 버튼이 생겼어요.

v0.2.1에서 바뀐 것

  • 친구 냥멍이끼리 놀아요 — 깨어 있는 친구 둘이 가까이 있으면 가끔 ♥ ♪ 인사를 해요. 친구를 다른 친구 옆에 끌어다 놓으면 바로 인사해요. 몇 분에 한 번은 둘이 가운데서 만나 공놀이나 술래잡기를 하고 제자리로 돌아가요. 노는 중에 만지면 바로 제자리로 돌아와요.
  • 친구 냥멍이 누르는 법이 바뀌었어요 — 한 번 누르면 한 줄 메시지 칸, 두 번 누르면 대화 창이 열려요(집과 같아요). 콕 찌르기는 오른쪽 클릭 메뉴에 있어요.
  • 친구 냥멍이 바로 옆이나 발밑 이름표를 눌러도 잘 눌려요.

v0.2.0에서 바뀐 것

  • 단체방을 바탕화면에 집으로 띄울 수 있어요 — 대화 창에서 단체방에 들어가 위쪽 [🏠 집 띄우기]를 눌러 보세요. 새 메시지가 오면 창문에 불이 켜지고 굴뚝에서 연기가 나요. 그 방 친구가 접속해 있으면 창문에 친구 얼굴이 보여요.
    집을 한 번 누르면 한 줄 메시지 칸, 두 번 누르면 대화 창이 열려요. 오른쪽 클릭하면 집 모양을 일곱 가지 중에서 고를 수 있어요(오두막·버섯집·딸기집·쿠키집·찻주전자집·우유팩집·컵케이크집).
  • 화면에 띄운 친구들이 훨씬 가벼워졌어요 — 컴퓨터 메모리를 예전의 절반 남짓만 써요. 모니터를 두 대 쓰면 친구를 다른 모니터로 끌어다 놓을 수도 있어요.
  • 1:1 대화방의 [나가기]가 [목록에서 지우기]로 바뀌었어요. 지워도 둘 중 누구든 메시지를 보내면 대화방이 다시 생겨요.
  • 친구 목록이 한 줄로 깔끔해졌어요. 접속 중인지는 초록 점으로 보여요.
  • 바탕화면 아이콘이 도트 고양이로 바뀌었어요.
  • 대화방을 만들지 못할 때 괄호 안에 이유가 같이 나와요. 그 글자를 만든 사람에게 알려 주시면 원인을 찾을 수 있어요.
  • 업데이트 뒤 말풍선은 짧게 알리고, 자세한 내용은 이 페이지에서 보게 바꿨어요.

v0.1.7에서 바뀐 것

  • 보냈는지 바로 보여요 — 냥멍이를 두 번 눌러 쓰는 한 줄 칸에서 메시지를 보내면, 칸 위에 초록색 "✓ 보냈어요"가 잠깐 떠요. 인터넷 문제로 못 보내면 "전송을 실패했어요"가 뜨고 쓴 글은 칸에 그대로 남아요.
  • 한 줄 칸 위 안내 글씨가 "메시지 보내기"로 바뀌었어요.

v0.1.6에서 바뀐 것

  • 내 상태를 고를 수 있어요 — 대화 창 위쪽의 📚 수업 중 · 💼 회의 중 · ⏳ 바빠요를 누르면, 그동안 냥멍이가 알림 카드를 쉬고 숫자만 쌓아 둬요. 수업 중은 50분, 회의 중은 1시간, 바빠요는 30분 뒤에 저절로 풀려요. 친구들 화면에도 "📚 수업 중"이 보여요.
  • 읽음 표시 — 내가 보낸 메시지 옆에 분홍 숫자 1이 붙고, 상대가 읽으면 사라져요. (상대도 이 버전이어야 사라져요)
  • 친구를 누르면 바로 대화 — 🐾 친구 목록에서 친구 이름을 누르면 1:1 대화방이 바로 열려요.
  • 안 읽은 개수 — 대화 목록에 점 대신 숫자로 나와요.
  • 이어 쓰기 — 냥멍이를 두 번 눌러 쓰는 한 줄 칸이 보내도 안 닫혀요. 다 쓰면 Esc나 바깥을 눌러 닫아요.
  • 같은 닉네임은 #번호를 붙여 구분하고, 메뉴의 💬 대화는 언제나 대화 목록부터 열려요.

v0.1.5에서 바뀐 것

  • 강아지 얼굴을 다듬었어요 — 코와 주둥이를 작게 하고 입을 연하게 해서, 고양이처럼 동글동글한 얼굴이 됐어요.

v0.1.4에서 바뀐 것

  • 숫자를 누르면 지난 메시지까지 보여요 — 메시지가 여러 개 쌓였을 때 분홍 숫자를 누르면, 최근 것만이 아니라 안 읽은 메시지가 위에서부터 차례로 보여요. 많이 쌓였으면 "앞에 N개 더"라고 알려 주고, 카드를 누르면 대화 창에서 전부 볼 수 있어요. 화면에 띄운 친구 옆 숫자도 똑같아요.
  • 친구를 6명까지 띄울 수 있어요 — 4명에서 늘었어요. 왼쪽에 자리가 모자라면 오른쪽으로 이어서 놓여요.

v0.1.3에서 고친 것

  • 클로드 작업 말풍선이 다시 떠요 — 원래 냥멍이도 깔려 있는 컴퓨터에서, 냥멍톡이 업데이트된 뒤 클로드 작업 말풍선이 안 뜨던 문제를 고쳤어요. 이번 업데이트를 받으면 저절로 다시 떠요.
  • 업데이트되면 바뀐 것을 말풍선으로 알려 드려요.

v0.1.2에서 바뀐 것

  • 닉네임을 바꿀 수 있어요 — 대화 창 맨 위 '내 코드' 칸의 ✏️를 누르면 돼요. 번호는 그대로이고(세니#2344 → 새이름#2344), 친구들 화면의 대화방·친구 목록·띄운 냥멍이 이름표도 같이 바뀌어요. 이미 친구인 사람은 그대로 친구예요. 새 친구에게는 바뀐 코드를 알려 주세요.

v0.1.1에서 바뀐 것

  • 냥멍이가 도트 그림이 됐어요 — 옛날 게임 같은 작은 네모 그림으로 바뀌었어요. 고양이·강아지 무늬 12가지와 소품 5가지 모두 도트로 나와요.
  • 분홍 숫자를 누르면 못 본 말풍선이 다시 떠요 — 메시지를 놓쳐서 숫자가 쌓였을 때 숫자를 누르면, 대화 창을 열지 않고도 못 본 카드들을 냥멍이 위에서 바로 볼 수 있어요. 한 번 더 누르면 접혀요.
  • 화면에 띄운 친구 옆에 숫자가 떠요 — 띄워 둔 친구가 보낸 메시지를 못 보면 그 친구 냥멍이 옆에 숫자가 남아요. 누르면 그 친구 머리 위에 말풍선이 다시 떠요.
  • 친구 냥멍이를 두 번 누르면 바로 한 줄 쓰기 — 대화 창 대신 말풍선 자리에 입력칸이 떠요. 쓰고 엔터 치면 끝. 대화 창은 오른쪽 클릭 → 💬 대화로 열 수 있어요.
  • 모습 고르는 칸이 잘리지 않아요 — 화면이 좁은 컴퓨터에서 무늬·소품이 다 안 보이던 것을 고쳤어요. 넘치면 옆의 ‹ › 를 눌러 넘겨 보면 돼요.
  • 혼자 상자에 쏙 들어가던 동작은 뺐어요.
