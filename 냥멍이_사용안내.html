냥멍이 사용안내

화면 구석에 사는 작은 고양이 또는 강아지(설정 ⚙에서 고를 수 있어요). 급식과 학사일정, 할 일을 챙겨주고, Claude Code를 쓰는 분에게는 Claude가 뭘 하는지도 말풍선으로 알려줍니다. Claude Code가 없어도 그대로 쓸 수 있어요.

1. 처음 한 번만

  • 고양이 옆 ⚙ 버튼(또는 고양이 오른쪽 클릭)으로 설정을 엽니다.
  • 이름을 적으면 "안녕, ○○!" 하고 불러줍니다.
  • 학교를 검색해서 고르면 급식과 학사일정이 나이스에서 자동으로 옵니다. (별도 로그인이나 키는 필요 없습니다)
  • 고양이 무늬도 여기서 고릅니다. 치즈, 흰둥이, 회색 줄무늬, 턱시도, 삼색이, 딸기우유. (강아지는 크림, 말티즈, 시바, 검둥이, 점박이, 초코)
  • 무늬 아래 줄은 소품입니다. 베레모, 리본, 꽃, 안경, 왕관 중 하나를 씌울 수 있고, 왼쪽 끝(빗금)을 고르면 안 씁니다.
  • 날씨는 학교를 정하면 그 동네로 자동으로 맞춰집니다. 다르게 보고 싶으면 설정에서 동네 이름(예: 종로구)을 적으면 됩니다.

2. Claude Code와 함께 쓸 때

  • Claude Code를 켜면 고양이가 깨어나서 지금 뭘 하는지(파일 읽는 중, 고치는 중, 명령 돌리는 중) 말풍선으로 보여줍니다.
  • 허락이 필요한 순간엔 말풍선에 허락 / 거절 버튼이 뜹니다. 누르면 터미널에 대신 키를 눌러줍니다.
  • Claude가 질문하면 선택지 버튼이 뜹니다. 직접 타이핑이 필요한 답은 콘솔 열기로 터미널로 갑니다.
  • 일이 끝나면 고양이가 폴짝 뛰고, 한동안 조용하면 잠듭니다.

3. Claude Code를 안 쓸 때도 (없어도 전부 됩니다)

  • ≡ 버튼: 오늘 급식(맨 위에 날씨도 같이), 오늘·내일 일정, 할 일, 집중. "+ 일정"은 달력에서 날짜를 고르고 내용을 적으면 되고, "+ 할 일"은 적어두고 끝나면 동그라미를 눌러 체크합니다.
  • 아침엔 날씨(비 오는 날엔 우산 이야기), 급식, 오늘 일정, 남은 할 일을 한 번에 알려주고, 점심 전에 급식을 한 번 더, 퇴근 무렵엔 남은 할 일을 한 번 말해줍니다.
  • D-day 챙기기: 일정 탭의 D-day 버튼을 누르면 앞으로 석 달 일정이 나옵니다. 중요한 것(시험, 행사 등)을 최대 3개까지 고르면 일정 탭 맨 위에 남은 날이 계속 보이고, 아침 인사에도 같이 알려줍니다.
  • 집중 타이머: 집중 탭에서 25분이나 45분을 고르면 그동안 냥멍이가 조용히 있고, 머리 위에 남은 시간이 뜹니다. 시간이 되면 같이 기지개를 켜자고 합니다.
  • 간식 주기: 설정 ⚙의 "간식 주기"를 누르면 그릇을 놓고 맛있게 먹습니다.
  • 50분 넘게 계속 앉아 있으면 고양이가 먼저 기지개를 켜며 같이 하자고 합니다. (설정에서 끌 수 있습니다)
  • 고양이를 톡 클릭하면 좋아합니다. 드래그하면 자리를 옮깁니다.
  • 가만히 있을 때 가끔 하품·세수·고개 갸웃·앞발 인사·엉덩이 씰룩을 하고, 심심하면 먼저 말을 겁니다. 자리를 비웠다 오면 반겨줍니다. 말 거는 횟수는 설정 ⚙의 "먼저 말 걸기"에서 안 함·가끔·보통·자주로 고를 수 있습니다.

4. 자주 묻는 것

  • 설치할 때 파란 경고창(SmartScreen)이 떠요. 개인이 만든 프로그램이라 뜨는 안내입니다. "추가 정보" → "실행"을 누르면 됩니다.
  • 고양이가 Claude 상태를 안 보여줘요. 설치 후 Claude Code를 새로 켜 보세요. 그래도 안 되면 C:\Users\(내이름)\.claude\settings.json 안에 cathook.exe가 들어 있는지 확인합니다.
  • 허락 버튼을 눌러도 터미널이 반응을 안 해요. 터미널 창이 최소화돼 있거나 다른 창에 가려지면 키가 안 들어갈 수 있습니다. 터미널을 화면에 두고 다시 눌러 보세요.
  • 바탕화면 아이콘을 눌러도 아무것도 안 떠요. 켜지다 실패하면 이유를 알려주는 창이 뜹니다. 창도 안 뜨면 ① 화면 오른쪽 아래 구석을 한 번 더 확인 ② 컴퓨터를 다시 켜고 시도 ③ 그래도 안 되면 설치 폴더(내 PC → C: → 사용자 → (내 이름) → AppData → Local → SeniWidgets → claude_cat)의 debug.log 파일을 만든 사람에게 보내주세요. 학교 PC에서 PowerShell 실행이 막혀 있으면 전산 담당자에게 허용을 문의해야 합니다.
  • 급식이 안 나와요. 설정에서 학교가 정해져 있는지, 인터넷이 되는지 확인합니다. 주말·방학엔 급식 정보가 원래 없습니다.
  • 새 버전이 나오면 어떻게 하나요? 냥멍이가 하루에 한 번 확인하고, 새 버전이 있으면 먼저 말풍선으로 알려줍니다. "지금 받기"를 누르면 알아서 받아서 갈아끼우고 새 모습으로 다시 켜집니다. 직접 확인하려면 설정 ⚙의 "새 버전 확인"을 누르세요. 업데이트 파일(냥멍이_업데이트.exe)을 따로 받았다면 그냥 실행만 하면 됩니다. 지금 것을 지울 필요는 없고, 이름·학교·할 일·일정 같은 설정도 그대로 남습니다.
  • 고양이를 없애고 싶어요. 고양이 옆 ×를 누르면 그 자리에서 사라집니다. 완전히 지우려면 Windows 설정 → 앱 → 냥멍이 → 제거. 이때 Claude Code 연결(훅)도 같이 풀립니다.
업데이트는 지우지 말고 그냥 덮어쓰세요. 새 설치 파일이나 업데이트 파일을 실행하면 있던 냥멍이를 알아서 내리고 새 것으로 갈아끼웁니다. 설정도 그대로 남습니다.

냥멍이는 인터넷으로 나이스 급식·학사일정, 동네 날씨, 새 버전 정보만 받아옵니다. 그 외 데이터는 전부 내 컴퓨터 안에만 저장됩니다. 만든 사람: Seni
